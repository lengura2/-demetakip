☁️ Cihazlar Arası Bulut Senkronizasyonu (Supabase)

Kapalı

iPhone ve bilgisayarınız arasında ödemelerinizi, taksit planlarınızı ve kredi kartlarınızı ortak kullanmak için ücretsiz Supabase projenizi bağlayın.

Supabase Tablo Kurulum Kodu (SQL) — İlk Kurulum İçin Tıklayın 
CREATE TABLE IF NOT EXISTS public.odeme_takvimi_sync (
  sync_id TEXT PRIMARY KEY,
  payload JSONB NOT NULL,
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

ALTER TABLE public.odeme_takvimi_sync ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Sync koduna gore erisim"
ON public.odeme_takvimi_sync
FOR ALL
USING (true)
WITH CHECK (true);
