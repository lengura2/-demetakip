# Ödeme Takvimi (PWA + Supabase)

Kişisel ödemeler, taksitli alışveriş planları, abonelikler ve kredi kartı hesap kesim tarihlerini takip etmek için hazırlanmış, çevrimdışı çalışabilen (PWA) ve Supabase destekli web uygulaması.

## GitHub'a Yükleme
1. Bu klasördeki tüm dosyaları (`index.html`, `manifest.json`, `sw.js`, `icon.svg`) GitHub deponuzun ana dizinine yükleyin.
2. **GitHub Pages** (`Settings > Pages > Branch: main`) veya **Vercel** üzerinden yayınlayın.
3. iPhone'da oluşan `https://` adresini **Safari** ile açıp **Paylaş → Ana Ekrana Ekle** seçeneğiyle tam ekran uygulama olarak kurun.
